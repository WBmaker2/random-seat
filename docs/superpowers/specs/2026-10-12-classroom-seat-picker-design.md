# 우리 반 자리 뽑기 웹앱 (Classroom Random Seat Picker) 설계 사양서

- **작성일**: 2026-10-12
- **상태**: 승인 대기 중 (Review Ready)
- **대상**: 교실 및 수업 환경 (선생님 및 학생)

---

## 1. 개요 및 목표

본 프로젝트는 교실에서 선생님과 학생들이 함께 사용할 수 있는 반응형 "우리 반 자리 뽑기" 웹 애플리케이션이다.
학생 수와 모둠 수를 입력하면 1번부터 마지막 번호까지의 학생 번호를 중복 없이 무작위로 섞어, 교실 책상 배치(칠판/교탁 기준, 모둠별 마주보는 형태)에 맞게 실시간 배치표를 렌더링한다.

### 핵심 가치 및 목표
1. **극적인 재미와 기대감**: 슬롯머신 스타일의 초고속 숫자 롤링 및 모둠별 순차 확정 애니메이션, 실감 나는 사운드와 축하 폭죽(Confetti) 연출.
2. **익명성 및 단순성 보장**: 학생 이름 입력을 배제하고, 깔끔한 '번호'(1번~N번)로만 직관적으로 표시.
3. **교실 맞춤형 UX**: 빔프로젝터/전자칠판 전체화면 모드, 원클릭 다시 뽑기, 키보드 단축키(Space/Enter), A4 인쇄 친화 모드 제공.

## 2. 화면 구성 및 디자인 시스템

### 2.1 칠판 테마 헤더 & 컨트롤 바
- **상단 칠판 배너**: 진한 초록색 분필 칠판 테마 배경(`bg-emerald-900`)에 분필 스타일 타이포그래피.
- **입력 필드**:
  - 학생 수 입력 (기본값: 24명, 범위: 1~60명)
  - 모둠 수 입력 (기본값: 6모둠, 범위: 1~15모둠)
  - 빠른 프리셋 버튼: `[20명 4모둠]`, `[24명 6모둠]`, `[28명 7모둠]`, `[30명 6모둠]`
- **액션 툴바**:
  - `[🎲 자리 뽑기]` (처음 시작 시) / `[🔄 다시 뽑기]` (배치 완료 후)
  - `[🔊 사운드 ON/OFF]` (음소거 토글)
  - `[⛶ 전체화면]` (교실 TV/빔프로젝터 몰입 모드)
  - `[🖨️ 인쇄/저장]` (인쇄용 클린 뷰 지원)

### 2.2 교실 구조 뷰 (Classroom Grid)
- **교탁 및 칠판 영역 (상단)**:
  - "칠판 / 교탁 (앞)" 레이블이 상단에 표시되어 학생과 교사가 실제 좌/우 방향을 헷갈리지 않도록 기준점 제공.
- **모둠별 책상 배치 (Desk Pods)**:
  - 모둠 카드는 2~4열 반응형 그리드로 정렬.
  - 모둠 헤더: `모둠 1`, `모둠 2` ... (개성 있는 파스텔톤 모둠 배지)
  - 모둠 내부: 2열로 서로 마주보는 책상 카드(Facing Pods) 배치.
  - 책상 카드: 큼직하고 둥근 카드 모서리, 부드러운 그림자, 선명한 번호 타이포그래피(`1번`, `15번`).

## 3. 알고리즘 및 상태 흐름

### 3.1 무작위 셔플 (Fisher-Yates)
```typescript
function shuffleArray<T>(array: T[]): T[] {
  const result = [...array];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}
```

### 3.2 공평한 모둠 인원 분배 (Round-Robin)
- 학생 수 `S`, 모둠 수 `G`일 때:
  - 기본 배정 인원: `base = Math.floor(S / G)`
  - 잔여 인원: `remainder = S % G`
  - 앞쪽 `remainder`개 모둠에는 `base + 1`명 배정, 나머지 모둠에는 `base`명 배정.
  - 예: 학생 25명, 모둠 6개 -> 모둠 1: 5명, 모둠 2~6: 4명씩 배정.

### 3.3 상태 머신 (Status Lifecycle)
- `IDLE`: 기본 설정 입력 화면 (아직 뽑지 않음 또는 빈 책상 가이드 표시)
- `ROLLING`: 번호가 초고속으로 회전 중 (각 자리가 50ms마다 무작위 번호 변경)
- `LOCKING`: 1모둠부터 차례대로 모둠 번호가 "탁!" 멈추며 고정 (순차적 딜레이 0.35초)
- `COMPLETED`: 모든 모둠의 자리가 확정되고 축하 파티클(Confetti) 폭죽 및 팡파르 재생

## 4. 애니메이션 및 사운드 효과 사양

### 4.1 시각 애니메이션
1. **회전 단계 (약 2.5초)**:
   - 숫자 카드가 슬롯머신처럼 빠르게 회전하며 가벼운 펄스(Pulse) 및 테두리 글로우 효과.
2. **순차 고정 단계**:
   - 모둠 1번부터 차례대로 번호가 확정되며 카드가 살짝 커졌다가 정착하는 팝업 바운스(`scale-110 -> scale-100`) 효과.
3. **완료 피날레**:
   - `canvas-confetti` 라이브러리를 통해 화면 좌/우/중앙에서 색종이 리본 및 스파클 폭죽 3연속 발사.

### 4.2 Web Audio API 기반 무종속 사운드 신디사이저
- 외부 mp3 파일 없이 순수 브라우저 AudioContext 오실레이터로 구현:
  - **Tick Sound**: 회전 중 짧은 고주파 틱 소리 (주파수 800Hz~1200Hz, 짧은 decay)
  - **Lock Sound**: 모둠별 확정 시 명쾌한 '탁!' 타격음 (Square/Sine 파형 조합, 440Hz -> 880Hz)
  - **Fanfare Sound**: 전체 확정 시 밝은 C 메이저 화음 (C5, E5, G5, C6 아르페지오 코드 팡파르)
- 브라우저 음소거 상태 및 사용자 토글 완벽 준수.

## 5. 예외 처리 및 유효성 검증

1. **학생 수 < 모둠 수**:
   - 경고 메시지 표시 ("학생 수는 모둠 수보다 많거나 같아야 합니다.")
   - [자리 뽑기] 버튼 비활성화.
2. **범위 초과 입력**:
   - 학생 수 1~60명 초과 입력 방지 (키보드 직접 입력 시 자동 클램핑).
   - 모둠 수 1~15모둠 초과 입력 방지.
3. **애니메이션 중복 방지**:
   - 추첨 진행(`ROLLING`, `LOCKING`) 중에는 컨트롤 조작 및 재클릭 잠금.

## 6. 기술 구현 스택 및 파일 구조

- **React 18 / TypeScript / Vite / Tailwind CSS**
- 디렉터리 구성:
  - `src/`
    - `components/`
      - `Header.tsx`: 칠판 배너 및 교실 테마 헤더
      - `ControlPanel.tsx`: 학생 수/모둠 수 입력, 프리셋, 컨트롤 버튼
      - `ClassroomBoard.tsx`: 교탁 및 모둠 책상 배치 그리드
      - `DeskPod.tsx`: 모둠별 테이블 및 마주보는 책상 카드
      - `SeatCard.tsx`: 번호 롤링 및 애니메이션 개별 좌석 카드
    - `utils/`
      - `seating.ts`: 셔플 및 분배 알고리즘
      - `sound.ts`: Web Audio API 사운드 생성기
      - `confetti.ts`: 축하 폭죽 연출
    - `App.tsx`: 메인 상태 및 단축키 관리
    - `index.css`: Tailwind 유틸리티 및 교실/칠판 커스텀 스타일
